# スケジェネ

撮影スケジュール（香盤表）を作成・管理・印刷するためのWebアプリケーションです。
React + TypeScript + Tailwind CSS で構築されており、B5縦サイズの印刷レイアウトに最適化されています。
スマートフォンでの編集にも対応し、現場での急な変更にも柔軟に対応できます。
オフラインでも動作するPWA（Progressive Web App）に対応しました。

## 特徴

*   **直感的なエディタ**: アコーディオン形式のUIで、基本情報、スケジュール、フッター情報をスムーズに入力できます。
*   **モバイル最適化**: スマートフォンでも操作しやすいレスポンシブデザイン。入力フィールドのサイズやレイアウトを調整し、タッチ操作での誤入力を防ぎます。
*   **リアルタイムプレビュー**: 入力内容は即座に右側のプレビュー画面（印刷レイアウト）に反映されます。
*   **複数日管理**: 1つのプロジェクトで複数の撮影日を管理でき、日付ごとのスケジュール作成が可能です。
*   **自動入力補助**: 時間の自動計算や、前日の情報コピー機能により、入力の手間を削減します。
*   **印刷最適化**: B5縦サイズに最適化されたレイアウトで、余白を最小限に抑え、情報を最大限に表示します。印刷時はヘッダーに背景色が付き、視認性が向上します。
*   **データ保存**: プロジェクトデータをJSONファイルとして保存・読み込みができ、バックアップや共有が容易です。ブラウザのローカルストレージにも自動保存されます。
*   **オフライン対応**: PWAとしてインストール可能で、インターネット環境がない場所でも利用できます。

## 機能一覧

### 1. プロジェクト設定
*   タイトル、組名の設定
*   キャストマスタ登録（役名・キャスト名）

### 2. スケジュール編集
*   **撮影行**: 時間、S#、P、D/N（M/Morning追加）、SCENE、備考、キャスト選択
*   **飯/移動/撤収行**: 食事（朝/昼/夕/夜）、移動、休憩、完全撤収などのスケジュール行を追加
*   **場所行**: 撮影場所の見出し追加（「第n現場」として自動ナンバリング）
*   **自動計算**: 終了時間の自動入力（場所行をスキップして計算）
*   **レイアウト自動調整**: キャスト数に応じてSCENEと備考の列幅を自動的に最適化
*   **最終日設定**: 最終日メッセージの表示

### 3. フッター情報
*   備考、車両、エキストラ情報の入力
*   **入り時間・キャスト表**:
    *   行の追加・削除が可能
    *   時間入力のクリアボタン
    *   場所入力の「同上」ボタン（前の行をコピー）
    *   印刷時のセル結合（時間・場所が同じ場合）
*   連絡先（監督・助監督）の入力
*   **印刷/PDF保存ボタン**: フッター情報の最後に配置され、スムーズに印刷へ移行可能

### 4. その他
*   **一括印刷**: 全日程をまとめて印刷プレビュー表示
*   **日付削除**: 不要な日付の削除機能（確認ダイアログ付き）

```bash
npm install

# 開発サーバーの起動
npm run dev
```

`main` ブランチにプッシュすると、自動的にビルドとデプロイが行われます。
